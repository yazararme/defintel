## Code

- `scripts/collect_news.py`
  - `request_headers(source)`: `{UA, Accept: */*}` + the source's optional `istek_basligi` dict.
    Sources without the field send exactly the old headers (tested).
  - `parse_body(source, content)`: the old feedparser block moved out of `read_feed()` unchanged;
    `tur: "html"` dispatches to `HTML_PARSERS[source["ayristirici"]]` (stdlib; an unknown name raises
    and becomes the source's error).
  - `parse_elbitsystems_uk()`: a narrow regex parser for that one page. After a site redesign it
    returns 0 items, so the source reads "feed parsed but empty" like a dead feed. It never invents
    rows.
  - The source filter accepts `tur in ("rss", "html")` (was `== "rss"`).
  - Fixture path: a feed may carry `{"body": "…"}`, which goes through `parse_body()`.
- `scripts/test_k6.py` (new, stdlib + feedparser when present) — 16 checks. A fake `requests`
  mimics Akamai (Chrome UA without Accept-Language → 403): the old Northrop entry reproduces the
  exact recorded error and the new entry gets through. The Northrop RSS fixture gives 10 items and the
  expected last 3. The Elbit UK parser gives 20 dated absolute-URL items and the expected last 3. A
  403 page or empty body gives 0 items. An unknown parser raises. An offline `collect_news.py
  --fixture` run (network-library trap from test_collect) reads both sources, with 0 failures and
  SİLME-YOK 2/2 equal. `data/news` is untouched.
  feedparser is not installed on the Mac, so the feedparser parse of the Northrop RSS is skipped
  there ("⚪ atlandı") and checked by stdlib instead. The workflow installs feedparser and runs it.
- `scripts/fixtures/k6-northrop-news-releases.xml`, `k6-elbitsystems-uk-recent-news.html.txt` (.txt so build.py's link check and Pages do not treat it as a page): raw
  live responses, unedited.
- `.github/workflows/k6-kaynak-test.yml` (**K6-3 (A)**): push to `rev21-33` only (+ dispatch),
  `pip install feedparser`, `python3 scripts/test_k6.py`. No secret and no real collection. The
  summary shows a table of both sources (type, request fix, parsed count, last 3 headlines) and
  a 🟢 line. Delete it before merge.
- `review/tools/smoke.py`: `k6_checks()` runs test_k6.py, checks the workflow (rev21-33 only, no
  secret, no real collection) and parses the JSON blocks in k6-kaynaklar.md.
