## What changed

| File | Change |
|---|---|
| `assets/app.js` `rescope()` | The numerator now counts **unique visible headlines**, not visible rows. A headline's identity is the row's first `a[href]` (fallback `data-search`). Both copies of a cross-listed headline are rendered from the same item, so they carry the same href. The denominator is unchanged (`unique_items`). |
| `review/tools/smoke.py` (KAPSAM_JS) | The roketsan check is now `"1 / {total}"`, no longer `"2 / {total}"`. The numerator is compared with a unique-href count, no longer a row count. A new broad search (`"a"` with no pill) must give a numerator equal to its unique count and ≤ the denominator. Every filtered numerator must be ≤ the denominator. |

The key is sound for today's page: an unfiltered page has 551 `[data-search]` rows and 536
distinct hrefs, which equals `unique_items` (536).
